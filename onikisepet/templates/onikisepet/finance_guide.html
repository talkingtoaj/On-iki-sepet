{% translate "Accounts and categories" %}

{% translate "An account is somewhere money actually sits: the cash box, a bank account, a savings fund. A category is what the money was for: rent, offerings, aid." %}

{% translate "Every account has one currency and keeps its own balance. Categories are separate for income and expense, so the same name can exist for both." %}

{% translate "Currencies" %}

{% translate "Amounts in different currencies are never added together. Each currency gets its own income, expense and net figure." %}

{% blocktranslate with currency=base_currency %}The dashboard also shows a grand total converted into {{ currency }}, using the exchange rate on file for the reporting date. It always states which rate it used.{% endblocktranslate %}

{% translate "If there is no rate on file for a currency, that currency is left out of the grand total and the total is marked incomplete. It is never quietly dropped." %}

{% translate "Balances and periods" %}

{% translate "Income and expense figures can be narrowed to a period. Balances cannot: a balance is the cumulative position including the opening balance, so it always covers everything up to today." %}

{% translate "Fixing a mistake" %}

{% translate "Nothing is ever deleted. A transaction can be corrected, and every change is recorded with who made it, when, and why." %}

{% translate "If an entry should not have existed at all, void it. Voiding keeps the record and its history, but removes it from every report and balance." %}

{% translate "Receipts" %}

{% translate "Cash expenses can carry a receipt image or PDF. Receipts hold financial information, so they are stored privately and only accessible to signed-in users with a role." %}
